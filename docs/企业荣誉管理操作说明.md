# 企业荣誉管理操作说明

## 一、进入管理页面

1. 打开飞书多维表格应用 **企业荣誉管理**。
2. 左侧选择 **企业荣誉表**，可进行荣誉信息的新增和编辑。
3. 选择 **企业荣誉概览看板**，可查看荣誉总数、官网展示数量、分类分布和排序结果。

## 二、新增荣誉

在 **企业荣誉表** 中点击 **添加记录**，填写以下字段：

| 字段 | 填写说明 |
| --- | --- |
| 分类 | 选择“发明专利”“相关荣誉”或“学术成果” |
| 荣誉名称 | 填写证书、奖项或论文成果名称 |
| 图片 | 上传荣誉证书或相关图片；每条记录至少上传一张 |
| 排序 | 填写数字，数字越小越靠前 |
| 官网展示 | 勾选后，荣誉会同步到官网展示；不勾选则不展示 |

## 三、修改和下线

- 修改荣誉名称、分类、图片或排序后，系统会同步更新官网内容。
- 暂时不想在官网展示时，取消勾选 **官网展示**，无需删除记录。
- 删除记录前请确认该荣誉不再需要保留；一般建议优先取消官网展示。

## 四、查看看板

- 看板中的“企业荣誉总数”反映表格中的荣誉记录数量。
- “官网展示荣誉数量”反映当前已勾选官网展示的记录数量。
- “荣誉分类分布”用于查看发明专利、相关荣誉和学术成果的数量占比。
- 如需查看明细，可返回 **企业荣誉表**，使用 **筛选** 或搜索功能查询。

## 五、注意事项

- 分类名称请使用系统已有选项，避免自行输入造成分类统计不一致。
- 图片应清晰、完整，优先上传证书或成果的正式图片。
- 排序数字不要重复；如需调整展示顺序，统一修改相关记录的排序值。
- 修改后请检查“官网展示”状态及看板数量是否正确。
- 荣誉内容同步到官网可能存在短暂延迟，请稍后刷新页面确认。
