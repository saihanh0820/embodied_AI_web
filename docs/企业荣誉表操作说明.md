# 企业荣誉表操作说明

## 一、页面和视图

进入飞书多维表格 **企业荣誉管理** 后，在左侧选择 **企业荣誉表**。顶部可按需要切换以下视图：

- **全部荣誉**：查看和维护全部荣誉记录。
- **官网展示**：查看已勾选“官网展示”的记录。
- **发明专利**：查看发明专利类荣誉。
- **相关荣誉**：查看奖项、资质等相关荣誉。
- **学术成果**：查看论文、会议成果等学术内容。
- **表单**：按表单方式录入新记录（如已配置）。

## 二、新增一条荣誉

1. 点击左上角 **添加记录**，或点击表格底部的“+”。
2. 按照以下要求填写信息：

| 字段 | 操作说明 |
| --- | --- |
| 荣誉编号 | 按现有编号规则填写，例如 `HON-0020`；如已自动生成则无需修改 |
| 分类 | 选择“发明专利”“相关荣誉”或“学术成果” |
| 荣誉名称 | 填写完整、准确的证书或成果名称 |
| 图片 | 上传清晰的证书、奖项或成果图片；建议每条记录上传一张主图 |
| 排序 | 填写展示顺序数字；同一分类内数字越小越靠前 |
| 官网展示 | 需要在官网显示时勾选，不展示时取消勾选 |
| 创建时间 | 通常由系统自动记录，不需要手动填写 |

3. 填写完成后，点击其他单元格或按回车，等待飞书保存。

## 三、编辑和下线

- 直接点击对应单元格即可修改分类、荣誉名称、图片、排序或官网展示状态。
- 暂时不在官网展示时，取消 **官网展示** 的勾选，不建议直接删除记录。
- 删除记录前应确认该荣誉已废弃且没有历史留档要求。

## 四、查询和整理

- 使用 **筛选**，可按分类或官网展示状态快速查找记录。
- 使用 **排序**，可按排序值或创建时间整理记录。
- 使用顶部视图，可快速查看某一分类或官网展示内容。
- 荣誉名称较长时，可点击单元格查看完整内容。

## 五、官网同步检查

1. 修改后确认“官网展示”状态正确。
2. 检查图片是否已成功上传并能正常预览。
3. 打开官网企业荣誉页面，确认分类、名称、图片和顺序显示无误。
4. 如暂未更新，请稍后刷新页面；仍未更新时联系网站维护人员检查同步状态。

## 六、注意事项

- 分类请使用已有选项，避免自行创建近似名称，影响看板统计。
- 荣誉名称应使用正式名称，不要使用过长的简称或内部备注。
- 图片涉及证书和公司信息，请勿上传无关或涉密文件。
- 修改完成后不要随意调整其他记录的排序值，避免影响官网展示顺序。
