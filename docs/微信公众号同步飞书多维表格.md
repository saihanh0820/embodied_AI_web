# 微信公众号自动同步飞书多维表格

## 功能

服务端定时读取微信公众号已群发文章，按文章链接写入项目已有的飞书新闻多维表格。重复执行不会重复创建；公众号封面会下载后上传到飞书附件字段。

## 配置

在 `.env` 中配置：

```env
WECHAT_NEWS_SYNC_ENABLED=true
WECHAT_MP_APP_ID=wx_xxxxxxxxxxxxx
WECHAT_MP_APP_SECRET=xxxxxxxxxxxxxxxx
WECHAT_NEWS_SYNC_INTERVAL_MS=300000
WECHAT_NEWS_BATCH_SIZE=20
WECHAT_NEWS_MAX_ARTICLES=100
WECHAT_NEWS_CATEGORY=company
WECHAT_NEWS_TAG=微信公众号
WECHAT_SYNC_UPDATE_EXISTING=true
WECHAT_SYNC_TRIGGER_TOKEN=replace-with-a-random-server-token
```

同时复用现有的 `FEISHU_APP_ID`、`FEISHU_APP_SECRET`、`FEISHU_NEWS_APP_TOKEN`、`FEISHU_NEWS_TABLE_ID` 和 `FEISHU_NEWS_FIELD_*` 配置。飞书新闻表至少应有：标题、发布日期、分类、标签、摘要、封面图（附件）、官网展示、详情链接。

如果“分类”是单选字段，`WECHAT_NEWS_CATEGORY` 必须填写飞书里真实存在的选项值，例如 `company` 或 `企业新闻`。

## 使用

服务重启后会按 `WECHAT_NEWS_SYNC_INTERVAL_MS` 自动同步。首次部署或需要补偿时，可以手动触发：

```powershell
Invoke-RestMethod -Method Post http://127.0.0.1:8787/api/wechat/sync -Headers @{ "X-Wechat-Sync-Token" = "your-token" }
```

查看状态：

```text
GET /api/wechat/status
```

公众号文章接口使用的是公众号后台 API，因此 `WECHAT_MP_APP_ID` 和 `WECHAT_MP_APP_SECRET` 必须是公众号的开发者凭据，不能使用普通用户登录密码。凭据只放在服务端，不能放进前端代码。

## 可选回调校验

如果还需要在微信公众号后台配置服务器 URL，可使用：

```text
https://你的域名/api/wechat/callback
```

并配置 `WECHAT_CALLBACK_TOKEN`。这个回调接口目前用于微信服务器 URL 校验；文章同步本身通过服务端轮询完成。
