# 销售线索表操作说明

## 一、进入线索表

1. 打开飞书，进入对应的多维表格应用 **weimou_web_leads**。
2. 在左侧选择 **销售部门表格**。
3. 表格中的每一行代表一条客户线索。

## 二、新增线索

- 网站联系表单提交的客户信息会自动写入表格。
- 如需手动添加，可点击顶部 **添加记录**，或在表格底部空白行录入。
- 主要字段填写如下：

| 字段 | 填写说明 |
| --- | --- |
| 姓名 | 客户或联系人姓名 |
| 留言内容 | 客户咨询的问题或需求 |
| 提交时间 | 记录产生时间，通常由系统自动填写 |
| 跟进状态 | 根据当前进度更新状态 |
| 负责人 | 指定负责跟进的销售同事 |
| 跟进备注 | 记录沟通时间、客户需求和下一步计划 |

## 三、跟进线索

1. 查看客户的 **姓名** 和 **留言内容**，了解咨询需求。
2. 在 **负责人** 字段指定跟进人员。
3. 联系客户后，及时更新 **跟进状态**。
4. 在 **跟进备注** 中记录沟通结果和后续安排，便于团队协作。

## 四、查询和整理

- 使用 **筛选**，可按负责人或跟进状态查看待处理线索。
- 使用 **排序**，可按提交时间查看最新线索。
- 可通过顶部搜索快速查找客户姓名或关键词。

## 五、注意事项

- 新线索应及时分配负责人并完成首次跟进。
- 跟进备注请写清日期、沟通结果和下一步动作。
- 不要随意删除客户线索或修改原始留言内容；如遇重复或无效线索，建议在跟进备注中说明原因。
- 涉及客户联系方式等信息时，请注意保密，仅限工作需要使用。
